# Creations of the Ill Minded

Portfolio landing page for The Ill Minded, the umbrella for Cyrus Dorbayan's ventures.

## Stack
- Single `index.html` file, self contained CSS and JS
- Google Fonts (Inter + Instrument Serif)
- Venture logos in `assets/logos/`

## Deploy
GitHub Pages from `main` branch. No build step needed.

## Domain
creationsoftheillminded.com
